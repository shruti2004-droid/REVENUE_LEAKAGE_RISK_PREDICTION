# Revenue Leakage Risk Prediction

## Project Overview
This project focuses on identifying potential revenue leakage risks using data analysis and machine learning techniques.

The workflow includes:
- Excel data cleaning
- Python exploratory data analysis
- Machine learning model building
- Streamlit app deployment

The final model predicts possible revenue leakage risk based on transaction-related features.

---

## Tools & Technologies Used
- Excel
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

---

## Key Highlights
- Performed data cleaning and preprocessing using Excel and Python.
- Conducted exploratory data analysis to identify revenue leakage patterns.
- Built a machine learning prediction model using Python.
- Developed an interactive Streamlit web application for real-time prediction.
